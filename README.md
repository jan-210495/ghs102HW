## بنية البحث

- صفحة الغلاف، فهرس المحتويات (مع اسم الطالب المسؤول)، إقرار بالأصالة وملاحظات منهجية.
- **القسم الأول — جان شادي عبود**: المقدمة العامة، تعريف الرأي العام (لغوياً واصطلاحياً وعند أبرز العلماء)، عشر خصائص مع أمثلة تقنية وكشفية، وثماني نظريات لتشكّل الرأي العام مرتبطة بالشبكات الرقمية.
- **القسم الثاني — وديع هيثم سلوم**: الخلفية الثقافية والنفسية والاجتماعية، الرأي العام وعلاقته بالسياسة الاقتصادية والقطاع المصرفي والتحول الرقمي، ثم الخاتمة والنتائج والتوصيات المشتركة.
- 38 مرجعاً موثّقاً (منشورات الجامعة الافتراضية السورية، كتب عربية متخصصة، دوريات محكّمة، دراسات كلاسيكية أجنبية، وبيانات ميدانية من «المؤشر العربي في سورية 2025» وتقارير البنك الدولي 2025–2026).
- ملاحق: جدول توزيع المهام والجهد البحثي، مسرد مصطلحات ثنائي اللغة، ونص المشكلة والأسئلة الفرعية.

## إعادة بناء الملفات (اختياري)

```bash
python3 -m venv .venv
.venv/bin/pip install python-docx
.venv/bin/python tools/build.py
```

- `tools/content_1.py` و`tools/content_2.py`: نص البحث وبنيته.
- `tools/references.py`: مسرد المراجع (مفاتيح التوثيق الداخلي).
- `tools/blocks.py` و`tools/build.py`: مولّد ملفات DOCX / HTML / MD.
- `assets/`: خط Amiri مُجزّأ ومُضمَّن في نسخة HTML، مع رخصة SIL OFL في `assets/OFL-Amiri.txt`.

> ملاحظة: أرقام الصفحات في فهرس المحتويات استرشادية، وتُحدَّث تلقائياً في Word من الحقول الموجودة في التذييل (يُحدِّثها Word عند الفتح).
